CONTROL JORNADA — DEMO FICTICIA v0.9.0 (2026-10-26)

Esta es la variante de demostración pública. El data.js revisado contiene 12 empleados ficticios, sin fichajes, marcas ni vacaciones reales. No equivale a una versión empresarial privada ni garantiza la seguridad de archivos históricos.

ANTES DE PUBLICAR UNA DEMO:
1. Ejecutar: python scripts/verificar_demo_publica.py
2. Revisar manualmente todos los archivos y el historial del repositorio; el script solo analiza data.js.
3. No subir archivos Excel/PDF/CSV/ZIP, datos personales o credenciales laborales, ni sustitutos de data.js con información real.
4. Revisar los cambios de manifest, version.json, app.js y sw.js si se actualiza la PWA.

La dirección HTTPS y GitHub Pages NO protegen documentos con información de empleados. No usar la demo para datos reales de jornada, vacaciones o bajas. Para uso empresarial hace falta un entorno privado con autenticación y control de acceso verificados, o una importación local diseñada para conservar datos solo en el dispositivo.

La función PDF es experimental; cada línea necesita revisión humana. Los cálculos oficiales siguen estando en el Excel original.

Más detalles: README.md y docs/SEGURIDAD_DEMO_PUBLICA.md
